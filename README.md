# 💸 Online Payment Management System (C++)

This is a small project made using C++ to manage user payments in a simple way. It runs in the terminal and lets you do three main things:

1. Add a user with a unique ID
2. Make a payment for that user
3. View all past payments for that user

---

## ✨ What You Can Do

- Add users by giving their name and a user ID  
  (User ID must have both letters and numbers, like `john123`)
- Make payments for any existing user  
  (Enter amount and payment method like UPI, CreditCard, etc.)
- Check payment history for each user

---

## 🛠 How to Run

1. Make sure you have a C++ compiler installed like `g++`
2. Save the code in a file called `main.cpp`
3. Open terminal and run:

```bash

    g++ Online_Payment_System.cpp -o program.exe
    ./program.exe

```
